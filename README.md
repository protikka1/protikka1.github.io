# protikka1.github.io

Source repository for the official portfolio and engineering showcase of **Abul Islam** (Google Workspace Administrator & Email Deliverability Specialist).

Live URL: [https://protikka1.github.io](https://protikka1.github.io)

## Technical Architecture
- **HTML5:** Semantic, single-page architecture optimized for technical hiring audits.
- **CSS3:** Native CSS variables supporting dark-mode contrast.
- **Vanilla JavaScript (`app.js`):** Client-side interactive DNS diagnostic simulator, tabbed case study routing, and contact handling.
- **Hosting:** GitHub Pages with continuous deployment from the `main` branch.
